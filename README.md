# AlviHub — Elegant Gold

UI scaffold dengan tema hitam transparan dan aksen gold.

## Isi
- `AlviHub.lua` — antarmuka UI dasar
- Menu Home, Player, Visual, Utilities, Survivor, Killer, Info
- Kontrol visual lokal: FullBright, No Fog, Shadows, Clock Time, FOV
- Panel draggable dan close button; layout menyesuaikan layar kecil

## Catatan
Ini adalah kerangka UI, bukan port penuh dari script pihak ketiga. Fitur exploit/cheat seperti aimbot, silent aim, auto-kill, bypass, auto-farm, dan remote loaders tidak disertakan. Gunakan hanya pada proyek atau pengalaman Roblox milik sendiri dan sesuai aturan platform.
